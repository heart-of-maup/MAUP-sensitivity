# On the sensitivities to the modifiable areal unit problem
This repository contains R scripts that calculate the sensitivities of a geographic observation to the modifiable areal unit problem (MAUP). It accompanies the following paper:
> Ye, X., & Chen, J. (2026). On the sensitivities to the modifiable areal unit problem. Big Earth Data, 1–36. https://doi.org/10.1080/20964471.2026.2692263

Both the paper and the code in this repository are openly available. If you use the MAUP sensitivity methods or the accompanying code in your research, please cite the paper above.

## The R scripts
This repository contains five R scripts:

### MAUP Sensitivity_vector.R
This script implements the vector-based procedural definitions of MAUP sensitivity proposed in Ye and Chen (2026), including heuristic algorithms where an exact procedural definition is not computationally feasible. Key functions include:
- `merging_sensitivity()`
- `splitting_sensitivity()`
- `continuous_reassignment_sensitivity()`
- `discrete_reassignment_sensitivity_area()`
- `discrete_reassignment_sensitivity_regions()`

### MAUP Sensitivity_raster.R
This script implements the raster-based procedural definitions of MAUP sensitivity proposed in Ye and Chen (2026). Key functions include:
- `merging_sensitivity_raster()`
- `splitting_sensitivity_raster()`
- `pixel_reassignment_sensitivity_raster()`

### MAUP Sensitivity_plot.R
This script provides shared plotting functions for visualizing sensitivity distributions generated by both the vector and raster implementations. Key functions include:
- `plot_sensitivity_distribution()`
- `plot_sensitivity_grid()`

### walkthrough_vector.R
This script reproduces the figures for example sets I–V in Ye and Chen (2026). Please note that due to the different randomization seeds, the resulting figures are not the same as the figures in the paper.
This script requires the following datasets in the `data` folder of the project directory, which can be downloaded [here](https://bit.ly/3ShpAor):

(a) 2023 U.S. county boundary shapefile
- `data/US_county/tl_2023_us_county.shp`
- `data/US_county/tl_2023_us_county.dbf`
- `data/US_county/tl_2023_us_county.shx`
- `data/US_county/tl_2023_us_county.prj`

(b) 2023 New York county subdivision boundary shapefile
- `data/US_subcounty/tl_2023_36_cousub.shp`
- `data/US_subcounty/tl_2023_36_cousub.dbf`
- `data/US_subcounty/tl_2023_36_cousub.shx`
- `data/US_subcounty/tl_2023_36_cousub.prj`

(c) 2023 ACS five-year subject tables
- `data/ACSST5Y2023.S2701-Data.csv`
- `data/ACSST5Y2023.S0101-Data.csv`

### walkthrough_raster.R
This script reproduces the figures for example set VI in Ye and Chen (2026). Please note that due to the different randomization seeds, the resulting figures are not the same as the figures in the paper.
This script requires the following datasets in the `data` folder of the project directory, which can be downloaded [here](https://bit.ly/3ShpAor):

(a) PRISM annual precipitation raster
- `data/raster_ppt_2023/prism_ppt_us_30s_2023.tif`

(b) 2023 U.S. county boundary shapefile
- `data/US_county/tl_2023_us_county.shp`
- `data/US_county/tl_2023_us_county.dbf`
- `data/US_county/tl_2023_us_county.shx`
- `data/US_county/tl_2023_us_county.prj`

## Usage
For vector examples, set `project_dir` in `walkthrough_vector.R` to the repository directory and run the script.
For raster examples, set `project_dir` in `walkthrough_raster.R` to the repository directory and run the script.
Make sure the `data` folder contains the required datasets listed above.
After the walkthrough scripts finish running, the resulting figures and `.rds` files can be found in the `outputs` folder.

## Repository versions
The current `main` branch contains a reorganized five-script version of the codebase, separating vector calculations, raster calculations, plotting functions, and reproducible walkthroughs.

The original four-script version associated with the published paper is archived as the GitHub release [`stable-version-20260812`](https://github.com/heart-of-maup/MAUP-sensitivity/releases/tag/stable-version-20260812).
