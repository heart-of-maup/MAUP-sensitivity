# MAUP-sensitivity
R script accompanying the paper "On the sensitivities to the modifiable areal unit problem".
This repository contains four R scripts:

## MAUP sensitivity.R
This R script contains procedural definitions (or heuristic algorithms for procedural definitions) of the proposed MAUP sensitivities in Ye and Chen (2026) for vector data.

## Walkthrough.R
When the 'data' folder under the project folder is prepared as required, this script reproduces the figures for example sets I-V in Ye and Chen (2026). Please note that due to the different randomization seeds, the resulting figures are not exactly the same as the figures in the paper.

## MAUP sensitivity raster.R
This R script contains procedural definitions (or heuristic algorithms for procedural definitions) of the proposed MAUP sensitivities in Ye and Chen (2026) for raster data.

## Walkthrough raster.R
When the 'data' folder under the project folder is prepared as required, this script reproduces the figures for example set VI in Ye and Chen (2026). Please note that due to the different randomization seeds, the resulting figures are not exactly the same as the figures in the paper.
